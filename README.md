# Emprende Frontend

Aplicación móvil multiplataforma desarrollada con Flutter.

## Requisitos

- Flutter SDK compatible con el proyecto.
- Android SDK para ejecutar en Android.
- API de Emprende ejecutándose desde `../backend`.

## Ejecutar

```powershell
flutter pub get
flutter run
```

Configura `API_BASE_URL` en `.env` para que apunte a una dirección accesible desde el dispositivo. En un teléfono físico, usa la IP local del equipo que ejecuta la API.
